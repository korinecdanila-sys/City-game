# Public repository hygiene

This repository is public at the time of setup. Branches, commits, pull requests and issue text may be visible. Avoid storing private game design materials, story spoilers, original private assets, personal information, credentials and signing keys. Do not enable paid services or deploy automatically.

If the owner chooses a private repository, re-evaluate collaborator and app permissions, CI quotas and release access. Making a repo private does not erase copies previously made by third parties.
