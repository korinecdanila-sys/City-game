# Decision and change control

- Owner-approved design decisions take precedence over proposals.
- Current project workspace is the canonical detailed record; this public register is a safe summary only.
- Preserve existing City-game files and both older game repositories.
- No source code, engine setup or implementation before explicit permission after preproduction.
- Keep story spoilers, private reference images, real-person details, tokens, signing keys and unreleased sensitive content outside this public repository.
- Do not purchase subscriptions or assets without approval.
- Record changes with date, scope, approval status, affected specifications and test implications.
- Do not claim that a prototype, placeholder, or design document is a finished game.
