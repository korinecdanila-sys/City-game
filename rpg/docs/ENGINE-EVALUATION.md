# Engine decision checklist — pending

Evaluate Godot and Unity (and alternatives only if materially useful) against:
- Actual Android rendering and profiling on the owner's device.
- Scene loading, memory and scalable quality.
- Animation blending, camera and cinematic QTE workflow.
- Input mapping, localization and UI.
- Deterministic off-screen simulation, serialization and save migrations.
- License terms, asset formats, commercial distribution and total cost.
- Automated headless export, CI, availability of Android SDK/JDK and signing workflow.
- Practical authoring on a phone or remote workstation.

Do not select solely on feature lists. Verify current official licenses and documentation, then use the smallest equivalent technical slice after coding is authorized. Record decision and tradeoffs. No engine version pinned yet.
